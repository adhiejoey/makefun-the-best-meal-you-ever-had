One sentence about the best meal ever had: a grandmother's rendang eaten cross-legged on cold tiles at 2 a.m. after Lebaran prayers, smoke and coconut on the tongue, ending with an apology to the goat — a concrete, personal memory that is funny, tender, and impossible to mistake for a stock line.

## How it works

`main.ts` writes the single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), using Node 22 standard library only and no network.
